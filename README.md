# MaryPortfolio

A fairy-garden-inspired personal portfolio for **Mary Janelle A Leano**, built with HTML, CSS, and JavaScript.

## View the website

Open `index.html` in a modern browser, or serve this directory with a local static server (for example, `python -m http.server 8000` and open `http://localhost:8000`). No build step, package installation, or environment variables are required.

## Project structure

```text
MaryPortfolio/
├── index.html       # Page content and accessible structure
├── styles.css       # Base styles and interactive components
├── reference.css    # Final visual design and responsive overrides
├── script.js        # Navigation, theme, search, effects, and music controls
└── assets/          # Images used by the site and the music track
```

## Features

- Responsive About, Experience, Projects, and Contact sections
- Day/night themes with saved preference
- Search and mobile navigation
- AlagaTrack project link and self-service kiosk project illustration
- Email copying with feedback
- Optional ambient music player (some browsers prevent automatic audio playback)
- Reduced-motion support

## Before publishing

Publish the contents of **this `MaryPortfolio` directory** as a static website. Check that you have the necessary rights to publish all images, illustrations, and the `Tinkerbell Calm.mp3` audio file. The original source images and working reference drafts are intentionally not included in the publish directory.

No deployment or Git command is required to run the site locally.
